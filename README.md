# DS 5080

Open this project in RStudio or in Positron, then run `_install.R` once to install the R packages this assignment needs. A first-time Bioconductor install can take a while.

Work in the `.qmd` file and render it to HTML (click **Render**, or run `quarto render` from a terminal in this folder). Render from inside this folder so relative paths to any `data/` files resolve.

Submit the rendered `.html` file on Canvas.
